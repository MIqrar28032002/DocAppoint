# DocAppoint - Doctor Appointment System

Simple web app to book doctor appointments. Made with ASP.NET Core MVC.

### Features
- User Register and Login
- Secure Dashboard
- Book Appointment in 60 seconds
- My History - See all your bookings
- Auto-fill email for fast booking
- Clean and Modern UI

### Tech Used
- ASP.NET Core MVC (.NET 10)
- Entity Framework Core
- SQL Server (SQLEXPRESS / LocalDB)
- ASP.NET Identity for Login
- Bootstrap 5 + Custom CSS
